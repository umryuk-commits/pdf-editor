# PDF Super Viewer (HWP,MD)

Windows용 가벼운 PDF & 한글(HWP/HWPX) & 마크다운(MD) 뷰어용 편집기입니다. Python(PySide6 + PyMuPDF)으로 만들어졌고,
설치 파일 없이 스크립트 하나로 실행합니다. HWP 문서 및 마크다운 문서는 전용 프로그램 미설치 환경에서도 자체 파서로 즉시 열람하고 주석을 달 수 있습니다.

## 실행 방법

### 다른 컴퓨터에서도 그대로 실행하기 (단독 실행 폴더)

`dist\PDF Super Viewer` **폴더 전체**를 복사해서 옮기면 됩니다. Python이나 어떤
라이브러리도 설치되어 있지 않은 Windows 컴퓨터에서도 그 폴더 안의
`PDF Super Viewer.exe`를 더블클릭하면 바로 실행됩니다. venv를 완전히 지운 상태에서
실제로 실행되는 것까지 확인했습니다.

- **폴더 전체**를 옮겨야 합니다(exe 파일만 따로 복사하면 안 됨 — 같이 있는
  `_internal` 폴더에 필요한 파일들이 들어있습니다). 전달할 때는 폴더를
  압축(zip)해서 보내고, 받는 쪽에서 압축을 풀어 실행하면 됩니다.
- 맨 처음 실행할 때 한 번은 Windows 보안 프로그램이 새 실행 파일을 검사하느라
  몇 초 걸릴 수 있습니다. 그 다음부터는 1초 이내로 바로 뜹니다.
  (처음에 "단일 exe 파일" 방식(`--onefile`)으로 만들었었는데, 그 방식은 실행할
  때마다 임시 폴더에 새로 파일을 풀어놓아서 매번 보안 검사가 걸려 계속 느렸습니다.
  지금의 폴더 방식(`--onedir`)은 파일이 그대로 있어서 처음 한 번만 느리고
  이후엔 빠릅니다.)
- 코드를 고친 뒤 새로 빌드하려면(이 프로젝트 폴더에서):
  ```
  venv\Scripts\pyinstaller.exe --noconfirm --onedir --windowed --name "PDF Super Viewer" main.py
  ```
  결과물은 `dist\PDF Super Viewer\PDF Super Viewer.exe`에 새로 생깁니다.

### 이 컴퓨터에서 개발용으로 실행하기

`pdf-editor` 폴더에서 `PDF Super Viewer.lnk` 바로가기를 더블클릭하세요. (코드를 고치면
바로 반영되는 방식이라 개발/테스트할 때 편합니다. `venv`가 있는 이 컴퓨터에서만
동작합니다 — 다른 컴퓨터로 옮기려면 위 단독 실행 파일을 쓰세요.)

명령어로 실행하려면:

```
cd C:\Users\user\gemini-workspace\pdf-editor
venv\Scripts\python.exe main.py
```

⚠️ 반드시 `venv\Scripts\python.exe`로 실행해야 합니다. 시스템에 기본으로 설치된
Python(`python main.py`)으로 실행하면 PySide6/PyMuPDF가 없어서 바로 에러가 나고
창이 사라집니다.

(첫 실행 전, 아직 라이브러리를 설치하지 않았다면: `venv\Scripts\pip.exe install -r requirements.txt`)

테스트용 샘플 파일은 `sample/` 폴더(git에는 올리지 않음)에 있습니다. "열기"로 바로 열어볼 수 있습니다.

## 기능

**보기**
- 여러 PDF, 한글(HWP, HWPX), 마크다운(MD, MARKDOWN) 문서를 탭으로 동시에 열어놓고 전환할 수 있습니다 (브라우저 탭처럼). 같은
  파일을 또 열면 새 탭을 만들지 않고 기존 탭으로 이동합니다. 파일을 여러 개
  한꺼번에 끌어다 놓으면 각각 새 탭으로 열립니다. 탭의 × 버튼이나 Ctrl+W로
  탭을 닫을 수 있고, 저장 안 된 내용이 있으면 닫기 전에 물어봅니다.
- **마크다운(MD/MARKDOWN) 문서 읽기 지원** — 기술 문서, README, 기획서 등 마크다운 파일을
  가독성 높은 전문 테크니컬 문서 스타일의 가상 PDF로 실시간 렌더링합니다. 제목(H1~H4), 본문, 코드 블록(```),
  인용구(>), 순서/불릿 목록, 표(Markdown Table) 등을 완벽히 파싱하여 깨끗하게 보여주며, 검색(Ctrl+F), 주석, 인쇄, PDF 내보내기를 모두 지원합니다.
- **한글(HWP/HWPX) 문서 완벽 지원** — 한컴오피스 프로그램이 설치되지 않은 환경에서도
  자체 파서(HWP 5.0 OLE2 바이너리 및 HWPX OWPML XML 파서)를 통해 문서 본문과 복잡한 표(Rowspan/Colspan 가변 너비 그리드 및 테두리/배경색)를 읽어와
  A4 규격의 가상 PDF로 즉시 변환·열람합니다. 한글 문서에서도 텍스트 검색(Ctrl+F), 형광펜,
  메모, 도형 그리기, 화면 캡처 삽입, 인쇄 등 모든 기능을 그대로 사용할 수 있으며, 원본 보호를
  위해 안전하게 PDF 파일로 내보내기/저장됩니다 (한컴오피스가 설치된 환경에서는 고품질 변환 자동 우선 적용).
- 파일 열기 / 저장 / 다른 이름으로 저장 (또는 창에 파일을 끌어다 놓기)
- 여러 페이지는 연속 스크롤로 이어보기 (스크롤만 하면 다음 페이지로 자연스럽게 넘어감)
- 왼쪽 페이지 목록(썸네일)에서 클릭으로 바로 이동
- 확대/축소는 툴바 버튼, `Ctrl + 마우스휠`, 또는 "폭 맞춤"/"화면 맞춤" 버튼
- 실행취소(Ctrl+Z) / 다시 실행(Ctrl+Y)
- 텍스트 선택/복사 — "선택" 도구에서 글자 위를 드래그하면 파란색으로
  강조되고, Ctrl+C 또는 마우스 우클릭 > "복사"로 시스템 클립보드에
  복사할 수 있습니다
- 찾기(Ctrl+F) — 문서 전체에서 글자를 찾아 다음/이전으로 이동, 찾은 곳은 주황색으로 표시
- 캡처 — 툴바의 "캡처"를 누르면 화면 어디든(다른 창, 이 프로그램 화면 포함)
  사각형으로 드래그해서 캡처할 수 있습니다. 캡처 직후 페이지 위에서 클릭(원본
  크기로 배치)하거나 드래그(원하는 크기로 배치)하면 그 자리에 바로 삽입되고,
  동시에 클립보드에도 복사되어 다른 곳에도 붙여넣을 수 있습니다(Esc로 취소)
- 인쇄 — 파일 메뉴 또는 툴바의 "인쇄"를 누르면 자체 인쇄 창이 뜹니다. 프린터
  선택, 인쇄 방향, 인쇄 매수, 페이지 범위(모든 페이지/현재 페이지)를 이 창
  안에서 전부 고르고, 오른쪽 미리보기로 확인한 뒤 바로 인쇄할 수 있습니다
  (Windows 자체 인쇄창은 미리보기를 지원하지 않아서, 아예 그 창을 쓰지 않고
  이 앱만의 인쇄 창으로 대체했습니다)
- 언어 — "언어 Language" 메뉴에서 한국어/English/中文/日本語 중 선택 (바꾼 뒤
  프로그램을 다시 시작하면 적용)
- 도움말 > 정보 — 버전/제작 정보 확인

**주석 도구** (드래그 또는 클릭으로 바로 적용)
- 하이라이트 / 밑줄 / 취소선 — 영역을 드래그하면 실제 글자에 맞춰 표시됨(텍스트 선택 방식)
- 노트 — 클릭한 위치에 말풍선 메모 추가
- 텍스트 박스 — 영역을 드래그해 새 텍스트 삽입 (연한 노란색 배경으로 표시되어
  경계가 잘 보이고, 지우개로도 정확히 클릭해서 지울 수 있습니다)
  - 만든 뒤 "선택" 도구로 클릭하면 파란 테두리 + 모서리 손잡이가 나오고,
    안쪽을 드래그하면 이동, 모서리를 드래그하면 크기를 바꿀 수 있습니다.
- 펜 — 자유롭게 드로잉
- 사각형 / 원 — 도형 그리기
- 지우개 — 기존 주석을 클릭해서 삭제
- 색상 팔레트 — 색상을 쓰는 도구(하이라이트/밑줄/취소선/펜/사각형/원)를 고르면
  전용 색상 팔레트 줄이 자동으로 나타나 바로 색을 고를 수 있고, "더보기..."로
  프리셋에 없는 색도 고를 수 있습니다
- 도구를 선택하면 마우스 포인터 모양도 그에 맞게 바뀝니다

**내용 수정**
- 텍스트 수정 — 영역을 드래그하면 그 안의 텍스트를 지우고 새 텍스트로 바꿀 수 있습니다.
  드래그가 정확하지 않아도 실제 글자 위치로 자동 보정되고, 원본 글자와 같은 위치·크기·
  색상·굵기/기울임을 유지합니다. 페이지가 90/270도로 회전되어 있어도 위치와 글자
  방향이 자동으로 보정되어 원본과 같은 방향으로 표시됩니다.
  (PDF는 문서 내 텍스트를 직접 고치는 게 아니라, 선택 영역을 지우고 그 자리에
  새 텍스트를 다시 그려 넣는 방식으로 동작합니다.)
- 페이지 메뉴 — 빈 페이지 삽입 / 현재 페이지 삭제 / 90도 회전

## 저장 방식

"저장"은 원본 파일을 바로 덮어쓰지 않고, 임시 파일에 먼저 저장한 뒤 원본 자리로
옮겨서 덮어씁니다 (중간에 오류가 나도 원본이 깨지지 않도록). "다른 이름으로 저장"은
새 파일로 저장합니다.

## 알아두면 좋은 점

- 대용량(페이지 수가 많거나 스캔본처럼 이미지가 무거운) PDF도 화면에 실제로 보이는
  페이지만 그때그때 그리도록 되어 있어서, 문서 크기와 상관없이 열기/확대·축소가
  가볍게 동작합니다. 썸네일도 문서를 열 때 조금씩 나눠서 채워집니다.
- 텍스트 수정은 "지우고 새로 쓰기" 방식이라, 원본과 폰트가 완전히 똑같지 않을 수
  있습니다 (기본 Helvetica 계열 폰트로 다시 그림).
- 스캔본(이미지로만 된 PDF)은 텍스트 수정 대상이 되는 "글자"가 없으므로,
  주석 도구 위주로 사용하세요.

## 폴더 구조

```
pdf-editor/
├─ main.py                 # 메인 윈도우 — 툴바/메뉴, 탭 관리, 파일 열기·저장
├─ canvas.py                # PDF 페이지 렌더링 + 도구별 마우스 동작 처리
├─ hwp_loader.py            # HWP / HWPX 문서 파서 및 PDF 변환 로더
├─ capture_overlay.py       # 화면 사각형 캡처 오버레이(캡처 기능)
├─ icons.py                 # 툴바 아이콘(QPainter로 직접 그림, 외부 파일 없음)
├─ print_dialog.py          # 자체 인쇄 대화상자 (프린터/방향/매수/범위 + 미리보기)
├─ i18n.py                  # 한국어/English/中文/日本語 번역 문자열
├─ version.py               # 버전/제작 정보 (새 버전 낼 때 이 파일만 수정)
├─ requirements.txt         # 필요한 라이브러리 목록 (PySide6, PyMuPDF, olefile)
├─ PDF Super Viewer.spec    # PyInstaller 빌드 설정 (재빌드 시 사용)
├─ README.md
└─ .gitignore

# 아래는 git에 올라가지 않음 (.gitignore 처리)
├─ venv/                    # 가상환경 (로컬 전용)
├─ build/, dist/            # PyInstaller 빌드 산출물 (dist/PDF Super Viewer = 단독 실행 폴더)
├─ sample/                  # 테스트/참고용 PDF (대용량·타사 저작물 포함이라 제외)
├─ __pycache__/             # Python 캐시
└─ PDF Super Viewer.lnk     # 이 컴퓨터 전용 바로가기 (로컬 절대경로 포함이라 공유 무의미)
```

## 기본 프로그램으로 설정하기

PDF 파일을 더블클릭하면 이 프로그램으로 열리게 하려면:

1. 아무 PDF 파일에 우클릭 > "다른 앱으로 열기" > "PDF Super Viewer" 선택
   (목록에 없으면 "이 PC에서 다른 앱 찾기"로 `dist\PDF Super Viewer\PDF Super Viewer.exe` 지정)
2. "항상 이 앱을 사용하여 .pdf 파일 열기" 체크 후 확인

Windows는 보안상 기본 앱 설정을 프로그램이 직접 바꾸지 못하게 막아놔서, 이 마지막
선택은 항상 사용자가 직접 해야 합니다. 이 설정은 지금 로그인한 계정에만 적용되고
다른 Windows 계정에는 영향을 주지 않습니다.

(프로그램 이름이 "PDF 편집기"에서 "PDF Super Viewer"로 바뀌면서 실행 파일 이름도
바뀌었습니다 — 예전에 이미 기본 프로그램으로 등록해두셨다면, 위 과정을 다시 한 번
해주셔야 새 실행 파일로 연결됩니다.)

## 버전 관리

`version.py`에 버전/제작 정보가 있습니다. 새 버전을 낼 때는 이 파일의
`APP_VERSION`(날짜)과 `APP_STAGE`(Beta 등)만 바꾸면 도움말 > 정보 창에 자동으로
반영됩니다.
